## ✨ Features

- **Private & Public Repositories:** Clone any public repository out of the box, or securely supply a GitHub Personal Access Token (PAT) for private codebases.
- **Hardware-Level Token Security (Windows DPAPI):** When saving a PAT, tokens are encrypted with `ProtectedData.Protect` using `DataProtectionScope.CurrentUser`. Your secret key is tied strictly to your Windows login identity and cannot be extracted from other machines or user accounts.
- **Shallow Local Ingestion (Depth = 1):** Powered by `LibGit2Sharp`. The tool executes a shallow single-commit clone to an isolated temporary directory, cleanly bypassing GitHub REST API rate limits and handling submodules natively.
- **Fast In-Memory BPE Token Estimation:** Streams the output digest through `Microsoft.ML.Tokenizers` using the `gpt-4o` (`o200k_base`) tokenizer in 64 KB memory chunks, providing an immediate token count upon completion.
- **Extensible JSON Preset System:** Switch between project types (C# ASP.NET Core, WPF Desktop, Java Spring Boot, Node.js, Python FastAPI/PyTorch, Rust, Go, etc.) or create, import, and export custom filter configurations to share across your engineering team.
- **File Size Thresholds & Binary Filtering:** Skips binary files using null-byte stream detection and enforces strict file size caps (e.g., skip files over 500 KB) to prevent context inflation.
- **JSON Theme Engine:** Features an authentic GitHub Primer Dark/Light aesthetic built on WPF's native `WindowChrome` with custom titlebar window snapping, supporting hot-reloadable custom theme files stored in `%APPDATA%\RepoPacker\Themes\`.

## 📑 Target LLM Digest Output Schema

Rather than wrapping code in ambiguous Markdown triple backticks (which frequently collide with READMEs and code comments), RepoPacker formats the final output as a clean, hierarchical XML envelope:

```xml
<repository>
  <metadata>
    <url>[https://github.com/organization/project](https://github.com/organization/project)</url>
    <generated_at>2026-10-20T09:45:00Z</generated_at>
    <file_count>38</file_count>
  </metadata>

  <directory_structure>
    src/Core/Engine.cs
    src/UI/MainWindow.xaml
    src/UI/MainWindow.xaml.cs
  </directory_structure>

  <files>
    <file path="src/Core/Engine.cs">
      // Clean, uncorrupted source code
    </file>
  </files>
</repository>
```

## 🚀 Getting Started

### Prerequisites

* [.NET 10.0 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
* Windows 10 / 11 (x64 or ARM64)

### Installation & Build

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/RepoPacker.git](https://github.com/your-username/RepoPacker.git)
   cd RepoPacker
   ```

2. **Restore NuGet dependencies:**
   ```bash
   dotnet restore
   ```

3. **Build the application:**
   ```bash
   dotnet build -c Release
   ```

4. **Run RepoPacker:**
   ```bash
   dotnet run --project RepoPacker.UI
   ```

## ⚙️ Configuration & Custom Themes

All user configurations persist in `%APPDATA%\RepoPacker\`:

* **`settings.json`**: Stores your active theme ID, last selected preset, and DPAPI-encrypted PAT.
* **`presets.json`**: Contains your active array of project presets. You can import and export bundles directly from the toolbar or edit this file by clicking **Open JSON**.
* **`Themes/*.json`**: Drop custom color schemes into the `Themes` folder. Click the folder icon in the titlebar to inspect or live-reload themes matching your personal editor style.
